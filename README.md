# bObby Rider

Браузерная 3D-игра «паркур по плиткам на транспорте» для ПК и телефонов.
Вся графика, музыка и звуки генерируются кодом — ассетов нет.

## Запуск

```bash
npm install
npm run dev       # дев-сервер (http://localhost:5173)
npm run build     # продакшен-сборка в dist/ (относительные пути — подходит для любых порталов)
npm run preview   # просмотр сборки
npm run bot -- 1 60   # headless-автопилот проверяет проходимость уровней 1..60 (SKILL=rival — с ошибками, как соперники)
```

Отладка: `?debug` открывает `window.__app`, `?ads=fail` имитирует недоступную рекламу.

## Управление

| ПК | Телефон |
|---|---|
| W/↑ — газ, S/↓ — тормоз | кнопки «Газ» / ▼ |
| A/D, ←/→ — руль | ◀ ▶ |
| Пробел — прыжок | «Прыжок» (одновременно жмёт газ) |
| Shift — нитро | кнопка нитро |
| R — к чекпоинту, Esc/P — пауза | кнопка паузы |

## Что внутри

- **Уровни:** 1–20 авторские (`RECIPES` в `src/world/generator.ts`), с 21-го — бесконечная детерминированная генерация
  с ростом сложности (сид = номер уровня). 5 миров-тем, чередуются каждые 10 уровней.
- **Сегменты:** пропасти, острова, лестницы вверх/вниз, узкие балки, зигзаги, повороты, трамплины, «адреналиновый спуск»
  (полутруба с ускорителями), движущиеся платформы, лифт, красные барьеры, вертушка, осыпающийся мост, батут, буст-прыжок.
- **Длина трасс:** базовый набор сегментов уровня удлиняется на 30% (`trackLengthMul` в конфиге) — теми же механиками.
- **Соперники-боты (с 3-го уровня):** уровни 3–6 — 1–2 соперника, 7–12 — 2–3, 13–20 — 3–4, дальше 4–5.
  Едут на автопилоте (`src/game/autopilot.ts`), ошибаются, падают и возрождаются на чекпоинтах; если дважды упали в одном месте
  или застряли — переносятся вперёд, чтобы гонка не вставала. Сила ботов растёт с уровнем. В HUD — место и метки на полосе
  прогресса. Бонус за место: 1-е +20, 2-е +10, 3-е +5 монет (`placeBonus`). Уровень засчитывается при любом месте.
- **Жизни:** 3 бесплатные на попытку → экран Game Over: «Возродиться» (rewarded), «Начать сначала», «Магазин», «Главное меню».
- **Магазин:** 8 видов транспорта за монеты + 4 эксклюзива за рекламу (3/3), 14 персонажей (мальчики и девочки),
  12 красок (радужная — за рекламу), 6 следов, 5 бустеров, бесплатные монеты, мешок монет 3/3, подарок дня.
- **Звук:** `src/audio` — синтезатор на Web Audio, 3 музыкальных трека, ~20 эффектов, гул мотора.

## Реклама

`src/ads/ads.ts`: `AdManager` + интерфейс `AdProvider`. Сейчас работает `StubProvider` (полноэкранная заглушка).
На время показа: пауза игры, остановка всего звука (`AudioContext.suspend`), блокировка ввода.
Для подключения площадки (Яндекс Игры, VK, CrazyGames, GameDistribution…) реализуйте `AdProvider`
и передайте его в `ads.init(new MyProvider())` в `src/main.ts`.

Точки показа:

- **Fullscreen** (кулдаун 45 с, первый — не раньше 25 с от старта): после уровня («Дальше»), «Начать сначала» на Game Over,
  выход в меню/карту из уровня, каждый 4-й рестарт подряд, первое «Играть» за сессию.
- **Rewarded:** возрождение, множитель награды (рулетка x2–x5), транспорт/скины 3/3, бустер, бесплатные монеты,
  мешок монет, пропуск уровня, подарок дня. Rewarded сбрасывает кулдаун fullscreen.

Все параметры — в `src/core/config.ts`.

## Структура

```
src/
  core/     конфиг, сохранения, ввод, защита страницы, события, RNG
  world/    генератор уровней, платформы, 3D-вид уровня, темы
  game/     физика (body.ts), игровой контроллер, сцена/рендер
  entities/ персонажи, транспорт, материалы
  render/   небо и облака, частицы, процедурные текстуры, геометрия
  audio/    движок, музыка, звуки
  ads/      менеджер рекламы и заглушка
  economy/  каталог предметов
  ui/       экраны, HUD, диалоги, стили, локализация RU/EN
tools/bot.ts  бот-проверка проходимости уровней
```
